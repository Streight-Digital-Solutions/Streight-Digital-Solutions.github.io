Build Process

Step 1: Create A Google Business Account

Creating a Google Business account allows you to login to all other accounts and later create a Google Business listing.

Step 2: Create A Github Account

Github Pages offers free static website hosting. Create your own account and then create a new repo.

Step 3: Install GIT

Now that you have a GitHub account, you will need to Install Git onto your PC.

Step 4: Install A Code Editor

Install VSCode or any code editor of your choice onto your PC so that you can modify your website code.
